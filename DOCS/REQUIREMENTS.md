## 一、网站定位

- **性质**：作家主页 + 独立博客
- **公众号**：三言二鱼（个人成长/感悟类内容）
- **网站名**：三言二语
- **域名**：rockdork.github.io（GitHub Pages）
- **作者/笔名**：章章

---

## 二、核心功能模块

### 2.1 博客文章（Posts）
- 路径：`/posts/`
- 普通文章列表，卡片式展示
- 所有从公众号搬运的文章**必须保留原标题**，绝不可自作主张改名
- 标签统一使用：**「自在生长」**
- 标签与日期同行显示，小胶囊样式，无描边

### 2.2 动态列表（Moments）✨ 新增
- 路径：`/moments/`
- **独立于博客文章**，不与 `/posts/` 混排
- 内容形态：短篇图文，类似小红书
- 支持两种形态：
  1. **图文**：封面图 + 短文字
  2. **纯文字**：只有文字，无封面
- 卡片比例：**16:9**
- 列表页：卡片网格布局（CSS Grid）
- 详情页：沉浸式视图，大图 + 文字
- front matter 字段：`featured_image`（封面图路径），**不可用 `cover`**（与 PaperMod 主题冲突）

### 2.3 作品页（Works）
- 路径：`/works/`
- 自定义模板：`layouts/works/single.html`

### 2.4 关于页（About）
- 路径：`/about/`
- **不显示日期**（front matter 中不留 `date` 字段）

## 三、风格规范

| 项目 | 要求 |
|------|------|
| 整体风格 | 极简留白，PaperMod 主题 |
| 副标题 | 无 |
| 文章目录 TOC | 关闭（ShowToc: false） |
| 标签位置 | 与日期同行，格式：`YYYY/MM/DD · #标签` |
| 标签样式 | 小胶囊，无描边，暖色调 |
| 首页 | 直接显示文章列表，无介绍块（已移除 homeInfoParams） |
| 首页第一篇文章 | 无 hero/特殊样式（已设置 disableSpecial1stPost = true） |
| 搜索图标 | SVG 放大镜（非 emoji 🔍），16px，与菜单项垂直居中 |
| 导航菜单 | 博客、标签、作品、动态、搜索（文字+SVG 图标） |

---

## 四、内容规范（红线）

1. **标题**：从公众号搬运文章时，**必须保留原标题**，AI 绝不可"优化"或重新起名
2. **标签**：统一使用「自在生长」（注意：是「自在」不是「自由」）
3. **日期格式**：`YYYY/MM/DD`
4. **动态封面字段**：必须用 `featured_image`，禁用 `cover`
